## 复现自动验收

使用项目后端依赖环境，从仓库根目录执行；默认测试均在临时目录创建数据库与图片，不读取开发数据库：

```sh
python -m pytest SystemCode/tests/test_c_acceptance.py -q
python -m pytest SystemCode/tests -q
cd SystemCode/frontend
npm run lint
npm run test:ci
npm run build
```

需导出逐例证据时，指定一个新目录；只有断言全部通过的案例才写入 passed=true。不要用旧目录残留文件判断新运行成功，以 pytest 退出状态为准：

```sh
ROADGUARD_ACCEPTANCE_OUTPUT=/tmp/roadguard-c13-new-run python -m pytest SystemCode/tests/test_c_acceptance.py -q
python .github/scripts/check_repository.py
python SystemCode/frontend/scripts/export_contract.py --check
```

测试阻断真实模型网络入口并固定 simulated 行程；账户密码仅是隔离 fixture，不属于用户凭据。现场演示使用后端 README 的启动方式，将 DB/UPLOAD 配置到新的隔离目录，并按 ACCOUNT_ROLES.md 创建巡查、调度与四个绑定施工队账号。禁止把日常开发库当作一次性测试库。浏览器执行上述七步，无需 API 密钥。

## 缺陷与限制

| 项目 | 结论 / 后续 |
| --- | --- |
| 新验收脚本初次失败 | 曾误从简化上传响应读取 detection_id；改为读取巡检详情，重新执行通过。不是产品接口缺陷 |
| 产品缺陷 | 本轮受测路径未发现阻断性缺陷；这不等于所有设备、并发条件或生产场景无缺陷 |
| GPT 语义质量 | 本轮 10 题是预设证据选择替身；8 条证据返回、1 条不足、1 条过期只代表接口测试状态，不能宣称 GPT 正确率 100% |
| GPT/Google | 用户选择暂不调用付费模型；没有真实 GPT/Google 调用，联通与真实质量均待配置及授权验收 |
| YOLO | 当前验收 Python 环境未安装 torch/ultralytics；仅显式模拟检测，不把浏览器结果当作真实图像推理或准确率评估 |
| 重启/中断 | 新应用实例可读回同数据库成功回执；既有测试用异常模拟中断与时间推进验证租约/旧尝试隔离，不是操作系统断电或强杀压测 |
| 地图与数据 | 仅保存停靠顺序示意；合成坐标、图片、行程不证明道路通行或模型质量 |
| 工程提示 | 仍有 JS 主包 >500 kB 提示、Starlette/httpx 弃用警告；不影响本次通过，依赖升级与拆包另安排 |
| 设备 | 内置浏览器和 390px 视口通过；未覆盖 Safari、Android/iOS 真机或辅助技术完整审计 |
