# Frontend - planned

Planned stack: React with a responsive browser interface.

Planned views:

- Image upload and Jurong task location selection.
- Low-confidence review queue.
- Accepted tasks with priority and decision trace.
- Four crew routes, distinct route colours and per-crew metrics.
- GA-versus-greedy comparison.
- Route explanation and supported change requests.

The crew display should render a collection of routes, with a default of four. The map must distinguish the agreed study boundary from any broader map viewport. Installation commands will be added after the frontend is scaffolded.
